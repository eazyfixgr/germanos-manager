# Αποφάσεις Έργου — Γερμανός Manager

Ημερομηνία: 4 Νοεμβρίου 2026

## D1 — Hosting για εμπορική χρήση
Το GitHub Pages παραμένει για demo/εσωτερική χρήση. Πριν από εμπορική διάθεση SaaS, το frontend θα μεταφερθεί σε κατάλληλο hosting. Διατηρούνται React/Vite, το repository και η συμβατότητα των routes.

## D2 — Εύρος πλάνου
Ακολουθείται το μεγάλο enterprise πλάνο (πολλαπλές φάσεις). Δεν γίνεται μία μαζική επανεγγραφή· κάθε φάση παραδίδεται και ελέγχεται ξεχωριστά.

## D3 — Ρόλοι
Τα δικαιώματα θα βασίζονται σε συμμετοχές εταιρείας/καταστήματος (organization/store memberships), όχι μόνο σε ένα πεδίο `role` του προφίλ. Διατηρούνται τα υπάρχοντα IDs και δεδομένα.

## D4 — Πρόγραμμα βαρδιών
Υιοθετούνται πραγματικά χρονικά διαστήματα βάρδιας και έλεγχοι στελέχωσης. Η δικαιοσύνη συνεχίζει να μετριέται και να διατηρείται μεταξύ μηνών.

## D5 — Πρώτη εταιρεία
Το υπάρχον κατάστημα θα γίνει η πρώτη εταιρεία. Ο σημερινός κύριος admin θα γίνει organization owner.

## D6 — Πρόσβαση υποστήριξης master
Ο master δεν θα έχει αόρατη άμεση πρόσβαση. Θα υπάρχει λειτουργία «πρόσβαση υποστήριξης» με αιτιολογία, χρονικό όριο και πλήρη audit, όπως σε IT support.

## D7 — Τρέχουσα βάση
Η σημερινή βάση θεωρείται demo/testing και διατηρείται για demo. Δεν θεωρείται production περιβάλλον.

## D8 — Εκκρεμή ρεπό
Τα εκκρεμή ρεπό είναι **προτιμήσεις** κατά την αυτόματη κατάρτιση προγράμματος. Μόνο τα εγκεκριμένα ρεπό είναι δεσμευτικά.

## D9 — Backups
Παραμένουν σε αναμονή σύμφωνα με οδηγία χρήστη. Για production διάθεση απαιτούνται automated encrypted backups και δοκιμασμένη επαναφορά.

## D10 — Deployment
Καμία παραγωγική διάθεση ή push χωρίς ρητή έγκριση. Οι αλλαγές της Φάσης 0 εφαρμόστηκαν μόνο στη demo βάση.
