# Γερμανός Manager

Διαχείριση καταστήματος Γερμανός — όλα σε ένα: στόχοι (πόντοι), παραγγελίες/παραλαβές με σκανάρισμα τιμολογίου, πρόγραμμα (ρεπό/άδειες/ωράρια) και διαχείριση υπαλλήλων.

Responsive web app (React + Vite + Tailwind), με **Supabase** για auth, βάση δεδομένων και realtime. Deploy σε **GitHub Pages**.

## Λειτουργίες

- **Login / Εγγραφή** στην αρχική σελίδα. Ο πρώτος χρήστης γίνεται αυτόματα **Admin**.
- **Ρόλοι**: `admin` (πλήρης έλεγχος) και `user` (υπάλληλος, λιγότερα δικαιώματα).
- **Στόχοι**: γενικός στόχος καταστήματος + ατομικός στόχος + projection, ανά μήνα. Ο admin τους αλλάζει, ή εκχωρεί το δικαίωμα (`can_edit_points`) σε συγκεκριμένους υπαλλήλους.
- **Παραγγελίες**: ροή κατάστασης `Νέα → Σε παραγγελία → Σε παραλαβή → Παρελήφθη → Έτοιμο → Ενημερώθηκε → Ολοκληρώθηκε`, με **σκανάρισμα barcode/τιμολογίου** (κάμερα ή φωτογραφία) που βρίσκει αυτόματα το είδος βάσει κωδικού.
- **Πρόγραμμα**: εβδομαδιαίες βάρδιες, ρεπό, αιτήσεις ρεπό/άδειας με έγκριση από admin.
- **Υπάλληλοι**: έγκριση νέων χρηστών, ενεργοποίηση/απενεργοποίηση, αλλαγή ρόλου, δικαιώματα.
- **Ιστορικό ενεργειών** (activity log).

## Setup — 2 βήματα που κάνεις ΕΣΥ (απαραίτητα)

### 1. Δημιούργησε το Supabase project

1. Πήγαινε στο [supabase.com](https://supabase.com) και κάνε **Sign in** (μπορείς με Google/GitHub).
2. Πάτα **New project** → διάλεξε ένα όνομα (π.χ. `germanos-manager`), ισχυρό database password, region `Frankfurt (eu-central-1)`.
3. Περίμενε να δημιουργηθεί (1-2 λεπτά).
4. Πήγαινε **Project Settings → API** και αντέγραψε:
   - **Project URL** (π.χ. `https://xxxx.supabase.co`)
   - **anon public** key (το δεύτερο κλειδί)
5. Πήγαινε **SQL Editor → New query**, κάνε paste ΟΛΟ το περιεχόμενο του αρχείου [`supabase/schema.sql`](supabase/schema.sql) και πάτα **Run**.

### 2. Δώσε τα κλειδιά στο deployment

Στο GitHub repo σου (`eazyfixgr/germanos-manager`), πήγαινε **Settings → Secrets and variables → Actions → New repository secret** και πρόσθεσε:

| Name | Value |
|------|-------|
| `VITE_SUPABASE_URL` | το Project URL |
| `VITE_SUPABASE_ANON_KEY` | το anon public key |

Μετά πήγαινε **Settings → Pages** και βεβαιώσου ότι το Source είναι **GitHub Actions** (γίνεται αυτόματα μετά το πρώτο push).

## Τοπική ανάπτυξη

```bash
npm install
# αντίγραψε το .env.example σε .env και βάλε τα κλειδιά
npm run dev
```

## Χρήση — πρώτα βήματα

1. Άνοιξε την εφαρμογή και κάνε **Εγγραφή**. Ο πρώτος λογαριασμός γίνεται αυτόματα **Admin**.
2. Πρόσθεσε υπαλλήλους (θα κάνουν εγγραφή μόνοι τους και εσύ τους εγκρίνεις από το μενού **Υπάλληλοι**).
3. Βάλε στόχους από το μενού **Στόχοι**.
4. Δημιούργησε παραγγελίες πελατών από **Παραγγελίες**.
