# Γερμανός Manager

Διαχείριση καταστήματος Γερμανός — όλα σε ένα: στόχοι (πόντοι), παραγγελίες/παραλαβές με σκανάρισμα τιμολογίου, πρόγραμμα (ρεπό/άδειες/ωράρια) και διαχείριση υπαλλήλων.

Responsive web app (React + Vite + Tailwind), με **Supabase** για auth, βάση δεδομένων και realtime. Deploy σε **GitHub Pages**.

## Λειτουργίες

- **Ρόλοι**: `master` (πάνω από όλους, δικός σου), `admin` (υπεύθυνος καταστήματος), `user` (υπάλληλος).
- **Εγγραφή με τύπο λογαριασμού**: Υπάλληλος ή Υπεύθυνος, με **όνομα + κωδικό καταστήματος**.
  - Υπάλληλος: χρειάζεται σωστό όνομα + κωδικό υπάρχοντος καταστήματος, αλλιώς δεν δημιουργείται.
  - Υπεύθυνος: αν ο κωδικός ανήκει σε υπάρχον κατάστημα → αίτηση προς τον **κύριο υπεύθυνο**· αν όχι → δημιουργεί νέο κατάστημα και γίνεται κύριος υπεύθυνος.
- **Εγκρίσεις (Αιτήσεις)**: οι αιτήσεις υπαλλήλων πάνε στον υπεύθυνο, των υπευθύνων στον κύριο υπεύθυνο. Badge με πλήθος εκκρεμών.
- **Κύριος υπεύθυνος**: μπορεί να ορίσει/αφαιρέσει κύριο ρόλο σε άλλους υπευθύνους (πάντα τουλάχιστον ένας).
- **Διαγραφή χρηστών** από μέσα (διαγράφεται και ο λογαριασμός σύνδεσης).
- **Master**: βλέπει και διαχειρίζεται όλα τα καταστήματα και όλους τους λογαριασμούς.
- **Στόχοι**: γενικός στόχος καταστήματος + ατομικός στόχος + projection, ανά μήνα.
- **Παραγγελίες**: ροή `Νέα → Σε παραγγελία → Σε παραλαβή → Παρελήφθη → Έτοιμο → Ενημερώθηκε → Ολοκληρώθηκε`, με **σκανάρισμα barcode/τιμολογίου**.
- **Πρόγραμμα**: βάρδιες, ρεπό, αιτήσεις ρεπό/άδειας με έγκριση.
- **Κατάστημα**: όνομα, κωδικός, διεύθυνση, τηλέφωνο, ωράριο.
- **Υπενθυμίσεις**: alert για έτοιμες παραγγελίες πάνω από 2 ημέρες χωρίς ενημέρωση πελάτη (badge στο μενού + Αρχική).
- **Κάδος ανακύκλωσης**: soft-delete χρηστών με επαναφορά (και οριστική διαγραφή από master), με καταγραφή ποιος διέγραψε.
- **Εισαγωγή από Excel/CSV**: στόχοι υπαλλήλων και παραγγελίες, με πρότυπο λήψης.
- **Εξαγωγή CSV**: στόχοι (ανά μήνα) και παραγγελίες.
- **Λογαριασμός**: αλλαγή κωδικού και στοιχείων.
- **Ασφάλεια master**: allowlist emails — μόνο αυτά μπορούν να είναι master.
- **Ετικέτα/QR παραλαβής**: slip με QR και εκτύπωση από την παραγγελία.
- **Ιστορικό ενεργειών** με ποιος/τι/πότε (activity log).

## Master

Ο **master** δεν ανήκει σε κατάστημα. Έχει ειδικό μενού (**Καταστήματα**, **Ασφάλεια**) και βλέπει/διαχειρίζεται όλα τα καταστήματα και όλους τους λογαριασμούς. Με τον επιλογέα καταστήματος στην κορυφή βλέπει τα δεδομένα κάθε καταστήματος.

## Setup (έχει ήδη γίνει)

Το Supabase project, το schema (`supabase/schema.sql`) και τα GitHub Actions secrets έχουν ήδη ρυθμιστεί. Η εφαρμογή είναι έτοιμη στο:

**https://eazyfixgr.github.io/germanos-manager/**

Αν χρειαστεί να ξανατρέξεις το schema σε άλλο project, τρέξε το `supabase/schema.sql` στο **SQL Editor** και πρόσθεσε τα secrets `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` στο repo.

> Σημείωση: η επιβεβαίωση email είναι απενεργοποιημένη (εσωτερική εφαρμογή). Κάθε νέος χρήστης χρειάζεται έγκριση από τον admin.

## Τοπική ανάπτυξη

```bash
npm install
# αντίγραψε το .env.example σε .env και βάλε τα κλειδιά
npm run dev
```

## Χρήση — πρώτα βήματα

1. Συνδέσου με τον λογαριασμό **master**.
2. Πήγαινε **Κατάστημα** και όρισε **κωδικό καταστήματος** (π.χ. `G1234`) και αποθήκευσε. Χωρίς κωδικό δεν μπορούν να εγγραφούν υπάλληλοι.
3. Οι υπάλληλοι κάνουν **Εγγραφή** ως «Υπάλληλος» με το όνομα + κωδικό καταστήματος και εγκρίνονται από **Αιτήσεις**.
4. Οι υπεύθυνοι κάνουν **Εγγραφή** ως «Υπεύθυνος»· αν βάλουν υπάρχοντα κωδικό, εγκρίνονται από τον κύριο υπεύθυνο.
5. Βάλε στόχους από **Στόχοι** και δημιούργησε παραγγελίες από **Παραγγελίες**.
